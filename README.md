# Exam-paper
# قالب برگه امتحانی لاتک

این مخزن شامل یک قالب آماده و استاندارد برای طراحی برگه‌های امتحانی با استفاده از **LaTeX** است. قالبی تمیز، خوانا و مناسب برای دانشگاه‌ها و مؤسسات آموزشی.

## ✨ ویژگی‌ها
- طراحی دوست‌داشتنی و حرفه‌ای برای سوالات تشریحی و تستی
- امکان تنظیم هدر شامل: نام درس، استاد، تاریخ و مدت زمان
- جایگذاری آسان نمره هر سوال
- خروجی PDF با کیفیت بالا

## 📁 ساختار فایل‌ها
- `exam-template.tex` : فایل اصلی قالب
- `questions.tex` : بخش سوالات (برای ویرایش سریع)
- `preamble.tex` : تنظیمات بسته‌ها و استایل

## 🚀 نحوه استفاده
۱. فایل `exam-template.tex` را در Overleaf یا کامپایلر دلخواه باز کنید.
۲. اطلاعات هدر (نام درس، استاد، تاریخ) را ویرایش کنید.
۳. سوالات خود را در بخش مشخص‌شده بنویسید.
۴. کامپایل کنید و PDF نهایی را دریافت نمایید.




---
**نکته:** برای استفاده نیاز به دانش پایه لاتک دارید. در صورت مشکل، راهنمای `latex-cheatsheet.md` را ببینید.
